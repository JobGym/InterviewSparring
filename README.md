# InterviewSparring
Gen AI 해커톤 [취도우복싱] - 취준생을 위한 AI 면접 준비 서비스


### 상세설명

두근두근 매번 떨리는 채용 면접. 무슨 질문이 나올지 궁금하지 않으셨나요?
이제 나의 이력서와 포트폴리오에 딱 맞는 질문들을 AI와 스파링 해보세요!

1. 나의 경력과 스택에 맞는 질문들을 추천받고 피드백도 받을수 있어요!

    - 내가 했던 프로젝트와 경력에서 나올수 있는 질문들을 미리보기
    - AI가 추천해주는 예상 꼬리질문들

2. 나는 회사의 인재상에 맞는 사람일까?
    - 나의 지원 동기와 장단점 등이 회사의 인재상에 맞게 작성됐는지 확인
    - 회사가 원하는 스택과 나의 스택 비교



### 고객의 문제점과 해결방안
- 면접 경험이 부족한 취준생 : 면접 경험이 적은 취준생은 면접 시뮬레이션을 통해 실제 면접과 유사한 상황을 체험하고, 면접에 대한 자신감을 키울 수 있습니다.
- 면접 질문에 대한 대답을 준비하고 싶은 취준생 : 면접 시뮬레이션은 다양한 면접 질문을 제공하고, 취준생이 이에 대한 대답을 준비해볼 수 있도록 도와줍니다.
- 면접 스타일을 파악하고 싶은 취준생 : 면접 시뮬레이션을 통해 취준생은 자신의 면접 스타일을 파악하고, 개선할 수 있는 부분을 찾을 수 있습니다.
